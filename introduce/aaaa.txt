**v2：增加 Mixer 前的桶间交叉旁路**

从 Mixer 前的 Token 中，分别对 common、item、creative 三桶取均值，得到 \(c、i、a\)。保留三个原向量，并加入两两逐元素乘积：

$$u_b=[c;i;a;c\odot i;c\odot a;i\odot a]$$

拼接结果经过投影、激活和归一化，再通过可学习的标量门控，与主干池化结果 \(p\) 融合：

$$z_2=\operatorname{LN}\!\left(p+\sigma(\alpha)\operatorname{LN}\!\left(\operatorname{GELU}(u_bW_b+b_b)\right)\right)$$

这条旁路使预测端能够直接利用**混合前的三桶表示及桶间乘性关系**。这里保留的是来源明确的桶级表示，并非未经压缩的全部字段。

**v4：增加两路指定的 Query–Item 交叉**

两路分别为：**查询意图与商品文本相关性**、**查询意图与商品身份及质量**。输入均取自 Mixer 前，经过 LayerNorm 和线性投影后，得到 128 维查询向量 \(q\) 与商品向量 \(i_j\)，其中 \(j\in\{1,2\}\)。

每一路将两侧表示、乘积和差值拼接，形成 512 维交叉输入：

$$u_j=[q;i_j;q\odot i_j;q-i_j]$$

通过独立的两层网络执行 \(512\rightarrow128\rightarrow768\) 变换，并由样本门控控制输出幅度：

$$g_j=\sigma\!\left([q;i_j;q\odot i_j]w_{g,j}+b_{g,j}\right),\qquad \delta_j=g_j\left(\operatorname{GELU}(u_jW_{1,j}+b_{1,j})W_{2,j}+b_{2,j}\right)$$

两路结果与主干池化表示 \(p\)、原有桶间交叉输出 \(r_b\) 一起融合：

$$z_4=\operatorname{LN}(p+r_b+\delta_1+\delta_2)$$

这里“定向”指**明确指定 Query 与哪组商品信息交叉**，为这两类关系增加独立的学习路径。其中，\([\,;\,]\) 表示拼接，\(\odot\) 表示逐元素乘法，\(\sigma\) 表示 Sigmoid。



**v2：增加一条保留 Mixer 前表示的桶间交叉旁路**

在 Token 进入 Mixer 前，额外分出一条支路：分别对 common、item、creative 桶内的 Token 取均值，得到三个向量 \(c、i、a\)，再计算两两逐元素乘积 \(c\odot i、c\odot a、i\odot a\)。

**三个原向量与三个乘积向量拼接 → 全连接投影与归一化 → 通过可学习权重，加到主干的池化结果上。**

这样，预测端既能使用 Mixer 学到的交互结果，也能直接利用三桶各自的表示及桶间关系。这里“保留完整语义”更准确地说，是**保留混合前、来源明确的三桶表示**；这些表示已经经过投影和平均，并非无损保留全部字段。

**v4：针对两类 Query–Item 关系，分别增加交叉支路**

v4 从 Mixer 前取出查询意图 Token，分别与两组商品 Token 配对：

| 交叉支路 | 输入组合 |
|---|---|
| 第一路 | 查询意图 × 商品文本及相关性信息 |
| 第二路 | 查询意图 × 商品身份及质量信息 |

每一路都先将两侧 Token **归一化并投影到 128 维**，再将查询向量、商品向量、两者的逐元素乘积和差值拼接，即 \([q;i;q\odot i;q-i]\)。拼接结果经过小型全连接网络变换为 768 维，再由随样本变化的门控控制加入量。两路输出与主干池化结果、原有桶间交叉结果相加，统一归一化后用于预测。

这里的“定向”就是**明确指定 Query 与哪组商品信息做交叉**，目的是单独加强这两类与搜索转化相关的关系。
